# Cardlopedia

Search every trading card game in one place: Magic: The Gathering, Pokémon, Yu-Gi-Oh!, One Piece,
Disney Lorcana, Digimon, Riftbound, Cyberpunk TCG and Star Wars: Unlimited. Includes a full
catalog browser, advanced search with game-specific filters, and daily TCGplayer prices.

It's a **static site** hosted free on GitHub Pages, with no server to run. A GitHub Action
rebuilds the card and price data every day.

## Put it on GitHub Pages

1. Create a new repository on GitHub (for example `cardlopedia`) and push this folder to its
   `main` branch.
2. In the repository, open **Settings → Pages** and set **Source** to **GitHub Actions**.
3. Open the **Actions** tab. The **Build and deploy** workflow runs on every push. The first run
   takes a minute or two; when it finishes, the site is live at
   `https://<your-username>.github.io/cardlopedia/`.

After that, the workflow runs again **every day at 02:30 UTC**, shortly after TCGCSV publishes
TCGplayer's new prices, and on every push. You can also run it by hand from the Actions tab
(**Build and deploy → Run workflow**).

**Custom domain:** add it under **Settings → Pages → Custom domain**. All links are relative, so
the site works both at a domain root and in a `/cardlopedia/` project folder.

**If a daily build fails** (for example, a card source is down), nothing is deployed and the site
keeps serving the previous day's data. GitHub emails the repository owner about failed runs.

## Run it locally

Requires Node.js 20 or newer. There are no npm dependencies.

```bash
npm run build
npm run dev
```

`npm run build` downloads everything into `site/data/` (about 45 MB, in under a minute), and
`npm run dev` serves the site at http://localhost:5173/. To test it the way GitHub Pages serves a
project site, pass a folder: `node scripts/serve.mjs 5173 /cardlopedia/`.

To rebuild only some data, name the parts: `npm run build -- op lor prices-op`. Parts are the game
ids `mtg pkm ygo op lor dgm rb cp swu`, plus `prices` (all prices) or `prices-<game>`.

## How it works

| Game | Searched | Data |
|---|---|---|
| Magic | Live, in the visitor's browser | [Scryfall](https://scryfall.com/docs/api) |
| Pokémon | Live, plus a daily card-text index | [TCGdex](https://tcgdex.dev) |
| Yu-Gi-Oh! | Live | [YGOPRODeck](https://ygoprodeck.com/api-guide/) |
| One Piece | Daily catalog, filtered in the browser | [OPTCG API](https://optcgapi.com) |
| Lorcana | Daily catalog | [Lorcana API](https://lorcana-api.com) |
| Digimon | Daily catalog | [DigimonCard.io](https://digimoncard.io) |
| Riftbound | Daily catalog | [Riftcodex](https://riftcodex.com) |
| Cyberpunk | Daily catalog; image links fetched live | NetDeck (the API behind the official card database) |
| Star Wars: Unlimited | Daily catalog | [SWU-DB](https://www.swu-db.com) |
| Haikyu!! Vobaca!! BREAK | Daily catalog, translated from Japanese | [Takara Tomy official card list](https://www.takaratomy.co.jp/products/haikyuvobacabreak/cardlist/) |
| Prices, all games | Daily | TCGplayer, via [TCGCSV](https://tcgcsv.com) |

Magic, Pokémon and Yu-Gi-Oh! are too large to download ahead of time, and their APIs accept
requests from any website, so the browser queries them directly. SWU-DB and TCGCSV don't accept
browser requests, and the smaller games are quicker to filter locally, so the daily build
downloads them into compact files. A visitor downloads a game's catalog (70–650 KB compressed)
the first time they open that game.

**Cyberpunk images:** NetDeck signs each image link for about five minutes. The site fetches
current links when Cyberpunk opens, and fetches them again if an image fails to load.

**Haikyu!! translations:** the game is only published in Japanese. Card names and rules text
are translated by hand in `scripts/haikyu-en.json`, using the glossary in `scripts/haikyu.mjs`;
teams, years, positions, rarities and two-character "duo" cards are translated by rule. When a
new set comes out, its new cards appear in Japanese, marked "Not translated yet", and the daily
build log lists each untranslated name and text so they can be added to `haikyu-en.json`.
TCGplayer doesn't sell this game, so it has no prices.

**Prices:** each card is matched to its TCGplayer product. Magic and Riftbound match by
TCGplayer product id, and Pokémon mostly does too. Yu-Gi-Oh! matches by set code; the other games
by card number and name, or by set and collector number. Brand-new cards may not have TCGplayer
listings yet.

## Project layout

```
site/                    Everything GitHub Pages publishes
  index.html, app.js     Search and results page
  advanced.html, advanced.js
  engine.js              Search, filters and price matching, run in the browser
  common.js              Shared helpers and the list of games
  style.css, favicon.svg, 404.html, robots.txt
  data/                  Generated by the build (not committed)
scripts/
  build-data.mjs         Downloads catalogs, filter options, the Pokémon text index and prices
  serve.mjs              Local static server for development
.github/workflows/pages.yml   Daily build and deploy
```

## Data sources and fair use

Card data comes from free community APIs, and prices are TCGplayer's via TCGCSV. Please respect
their terms: keep the site free to use, and keep the daily build to once a day. The Cyberpunk
source is undocumented and could change without notice. Card images load from each source's own
servers.

Cardlopedia is an unofficial fan project and is not affiliated with or endorsed by any of the
games' publishers. Card names, images and text belong to their respective owners.
